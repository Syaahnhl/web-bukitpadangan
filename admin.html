Kredensial Sinkronisasi GitHub PAT

Personal Access Token (PAT) disimpan secara aman di penyimpanan peramban lokal (LocalStorage) tablet/ponsel Tuan. Token ini memberikan izin langsung ke GitHub API untuk mempublikasikan revisi teks, katalog menu, dan ketersediaan meja tanpa perlu membuka laptop.

  • Token hanya disimpan di browser perangkat Anda, tidak di-share ke umum.
  • Membutuhkan permission repository: repo:content (write).
  • Setiap perubahan yang disimpan akan langsung memicu deployment otomatis Netlify dalam kurun waktu 1-2 menit.
